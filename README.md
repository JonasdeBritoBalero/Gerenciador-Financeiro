# Gerenciador-Financeiro

Objetivo: Gerenciar os meus investimentos, voltado para FIIS e Ações.

## Tarefas:
- Atualização da cotação dos ativos.
- Atualização do Patrimonio real.
- Aviso sobre dividendos que serão realizados.
- Registro em banco de dados e também atualização em planilha(Google Sheet).
- Registro de compra ou venda de ativos.
- Elaboração de um relatório sobre o patrimonio e dividendos.

## Organização das pastas
- data: Banco de dados e manipulação do banco.
- Sheets: Atualização da planilha(Google Sheet).
- WebScraping: Verificação do site para obter os valores e dividendos dos ativos.
